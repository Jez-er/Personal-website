# Andriy Chernenko — Portfolio

A static personal portfolio website in English with a milk / chocolate / forest-green visual system.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling and animations
- `script.js` — scroll reveal, cursor glow and placeholder interactions
- `assets/profile.jpg` — provided profile photo
- `Andriy_Chernenko_CV.pdf` — provided CV

## Replace placeholders
- GitHub / Instagram / other social URLs in `index.html`
- Project names, descriptions, technologies and links in the Projects section
- Any wording you want to personalize further

Open `index.html` in a browser to preview the site.
